Fluxo recomendado

Este guia foi preparado para tenants de validacao e trials de 15 dias. Acesse o tenant, abra Primeiros Passos, baixe o gateway ou agente e acompanhe os dados reais nas telas de Hosts, Logs, Traces e Gateways.

  1. Instale ao menos um gateway quando houver rede local, segmentacao ou varios hosts atras do mesmo cliente.
  2. Instale agentes Linux ou Windows diretamente nos hosts que serao monitorados.
  3. Valide se o host aparece em Hosts com status online.
  4. Valide se o gateway aparece em Gateways com heartbeat recente.
  5. Para redes locais, execute o discovery em Ativos de rede; com gateway online, a task deve ser enfileirada para o gateway do tenant.
  6. Para syslog remoto, aponte os equipamentos para o gateway nas portas UDP/TCP 514; 6514 fica reservado para syslog TLS.
  7. Suba o laboratorio Docker de aplicacoes e gere acessos HTTP para validar logs, traces e RUM/APM.
  8. Abra um ticket se encontrar falha; a plataforma executa uma analise inicial por IA antes da triagem operacional.

Laboratorio Docker

O laboratorio fica em lab/validation-apps e cria tres aplicacoes pequenas: .NET, Java e PHP/HTML.

cd lab/validation-apps
docker compose up -d --build
curl http://localhost:5081/health
curl http://localhost:5082/health
curl http://localhost:5083/health

Em ambiente de cliente, substitua localhost pelo IP ou DNS da VM onde o laboratorio estiver rodando.

Checklist para evidencias

Durante a validacao, gere prints diretamente do ambiente do cliente e anexe aos tickets quando necessario.

  • Primeiros Passos: links de instalacao e endpoints oficiais.
  • Gateways: heartbeat, cluster, prioridade, failover e endpoint publico.
  • Hosts: host online, consumo de CPU/RAM e modo de monitoramento.
  • Logs e Traces: eventos reais ingeridos, filtros e correlacao por trace id.
  • Tickets: abertura, resposta e analise inicial por IA.

Os prints oficiais da documentacao comercial serao recriados somente depois da instalacao real dos primeiros agentes/gateways, para evitar imagens sem dados ou capturas incorretas.
